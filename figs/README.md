# /figs — UNUSED. The figure set is in `/figures`.

**This directory is empty and produces nothing.** The figures this paper reports are
in **`/figures`**, generated by `python/make_figures.py`, with their provenance
recorded in `figures/figure_provenance.json` and checkable by
`python make_figures.py --verify`.

Rewritten 2026-09-13. The previous version of this file, dated 2026-09-04, described
nine figures built by `python/build_fig*.py`. None of those files exists, the scripts
do not exist, and — the reason this mattered enough to rewrite rather than leave —
the figure list described **a research design that has since been withdrawn**:

| named in the old version | why it is gone |
|---|---|
| `fig1_study_area.pdf` — "Amphan landfall, treatment + control districts" | The analysis is nine seasons and the full §1.1 cyclone catalogue, not a single-event treatment/control comparison. |
| `fig3_did_coefplot.pdf` — "DiD coefficient plot" | §4.1 withdraws every causal claim from §3.8. The design fails its own §3.9 timing placebo. Nothing is reported as a difference-in-differences effect. |
| `fig4_event_study.pdf` — "with parallel-trends test" | Same withdrawal. `python/event_study.py` still exists and its table is reported as a descriptive diagnostic, not as identification. |
| `fig7_parallel_trends.pdf` — "Pre-cyclone parallel-trend lines" | Same withdrawal. |
| `fig2`, `fig5`, `fig6`, `figS1`, `figS2` | Sentinel-2-era plans, superseded by the Sentinel-1 substrate change. |

A reader who found the old text would have concluded this paper performs a
difference-in-differences on treatment and control districts with a parallel-trends
test. It does not, and §4.1 says so. The original plan is preserved where it belongs
— in `osf/OSF_PreReg_v0.2.md` §4 and in `analysis/deviation_log.md`, which is the
record of what changed and why.

The directory is kept rather than deleted so this note has somewhere to live.
