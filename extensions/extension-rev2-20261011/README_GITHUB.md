# Post-hoc extension revision 2

This directory publishes the frozen plan, extension scripts, calibration,
summary tables and technical records. It does not replace original tag v1.0.0.
The complete self-contained extension package, including the 59-file original
source snapshot and large fit caches, is deposited separately at Zenodo:
https://doi.org/10.5281/zenodo.23309957

The DOI above is reserved during staging; publication must be checked before
calling the deposit public. This GitHub subset is not a standalone replay kit.
The full-package manifest describes the deposited archive, not this subset.
For reproduction, extract the full Zenodo extension and obtain the two external
inputs from https://doi.org/10.5281/zenodo.22750338 as in README_PUBLIC.txt.
